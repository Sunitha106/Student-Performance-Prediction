# Student Performance Prediction

## 📌 Overview

This project uses machine learning to predict whether a student
will pass or fail based on study hours and attendance percentage.

## 🎯 Objective

To build a classification model that can identify student
performance using basic academic-related features.

## 🛠️ Technologies

- Python
- Pandas
- Scikit-learn
- Jupyter Notebook
- Random Forest Classifier

## 📊 Dataset

The dataset contains student information including:
- Study Hours
- Attendance Percentage
- Performance/Result

## ⚙️ Methodology

1. Load the dataset
2. Explore the data
3. Perform preprocessing
4. Select relevant features
5. Split data into training and testing sets
6. Train Random Forest Classifier
7. Make predictions
8. Evaluate the model

## 🤖 Machine Learning Model

Random Forest Classifier was used for the pass/fail
classification task.
